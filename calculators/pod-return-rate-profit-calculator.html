Print on Demand

POD Return Rate Profit Calculator

A return does not just lose a sale — the item was already printed and shipped. This calculator shows what a return rate really costs.







—

Formula

Profit per kept unit = retail price − base cost − fulfillment shipping. Loss per returned unit = base cost + fulfillment shipping + return shipping cost. Total profit = (kept units × profit per kept unit) − (returned units × loss per returned unit). Returned units are refunded, so no retail price is kept on them.

How it works

Enter how many units sold, the retail price, the base cost and fulfillment shipping, the return rate as a percentage of units sold, and any return shipping cost you pay per return. The calculator splits sales into kept and returned units, profits the kept ones, charges the full printed-and-shipped cost against the returned ones, and compares the total with a zero-return result.

Worked example

100 units sold at $28.00, base cost $9.25, fulfillment shipping $4.75, a 10% return rate and no return shipping cost: kept units 90, returned units 10. Profit per kept unit $28.00 − $9.25 − $4.75 = $14.00, so profit on kept units is 90 × $14.00 = $1,260.00. Loss per return is $9.25 + $4.75 = $14.00, so returns lose 10 × $14.00 = $140.00. Total profit $1,260.00 − $140.00 = $1,120.00, which is $11.20 per unit sold, against $1,400.00 with no returns. The $9.25 base cost and $4.75 shipping are Printful's published 2026 figures for a Gildan 5000 tee and starting US shirt shipping.

FAQs

Why does a return cost the full base cost plus shipping?

Because the item was already printed and shipped before the buyer sent it back. A returned POD item usually cannot be resold as new, so the money spent making and shipping it is gone even though the retail price is refunded.

Does this assume the buyer gets a full refund?

Yes. Returned units keep no retail price in this calculation. If you charge a restocking fee or only partly refund, add that kept amount back by reducing the loss per return in your own figures.

What return rate should I use?

Your own past return rate for that product type, if you have one. If you do not, try 5% and 10% side by side — the gap between them shows how sensitive your profit is before real returns arrive.

Is return shipping included?

Only if you enter it. The default is $0, which fits a policy where the buyer pays return shipping. If you pay for the return label, enter that cost per return and it is added to the loss on every returned unit.

How do I cut the damage from returns?

Accurate size charts, true-to-life mockups and clear product descriptions reduce wrong-size and not-as-described returns, which are the two return reasons a POD seller can most influence before an order is placed.
